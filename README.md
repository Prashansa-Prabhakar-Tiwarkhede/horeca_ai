# 🍽️ Smart HORECA AI
### Intelligent Food Demand & Waste Reduction System
> Final Year / Hackathon Level Project

---

## Problem Statement

Hotels, Restaurants, and Cafés (HoReCa) waste 30–40% of all food prepared daily.
This leads to:
- Direct revenue loss (₹ wasted ingredients)
- Environmental impact (food in landfills)
- Operational inefficiency

**Smart HORECA AI** solves this by using Machine Learning to forecast demand,
suggest optimal preparation quantities, and alert staff to high-waste risk events
— before they happen.

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train ML models (only once)
python train_models.py

# 3. Run the web app
python run.py
```

Open → **http://localhost:5000**

Register as the first user → you'll be made **Admin** automatically.

---

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Redirect to dashboard / login |
| GET/POST | `/login` | Auth |
| GET/POST | `/register` | Register |
| GET | `/dashboard` | Analytics dashboard |
| GET/POST | `/predict` | AI prediction form |
| GET | `/history` | Prediction history |
| GET | `/admin` | Admin panel |
| POST | `/api/predict` | JSON prediction API |
| GET | `/api/dashboard-stats` | Chart data API |

### API Example

```bash
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "Meal_Time": "Lunch",
    "Service_Type": "Buffet",
    "Day_Type": "Weekday",
    "Customers_Count": 150,
    "checkout_price": 145,
    "base_price": 175,
    "emailer_for_promotion": 0,
    "homepage_featured": 0
  }'
```

Response:
```json
{
  "success": true,
  "predicted_demand": 234.5,
  "predicted_wastage": 18.3,
  "suggested_quantity": 258.1,
  "waste_percentage": 7.1,
  "risk_alert": "LOW"
}
```

## Deploy to Render (Free)

1. Push code to GitHub
2. Go to [render.com](https://render.com) → New Web Service
3. Connect your GitHub repo
4. Settings:
   - **Build Command:** `pip install -r requirements.txt && python train_models.py`
   - **Start Command:** `gunicorn run:app`
5. Click Deploy

## Deploy to Google Cloud Run

```bash
# Build and push container
gcloud builds submit --tag gcr.io/YOUR_PROJECT/horeca-ai

# Deploy
gcloud run deploy horeca-ai \
  --image gcr.io/YOUR_PROJECT/horeca-ai \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated
```
